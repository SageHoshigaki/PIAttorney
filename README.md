# InventCare

React + Vite + Tailwind CSS v4 + Framer Motion.

## Run

npm install
npm run dev

## Build

npm run build
npm run preview

Content is adapted from the supplied InventCare brief. This is a responsive single-page brand website. The contact form opens a prefilled email; it does not store submissions or send them automatically. Secure medical intake, CRM, analytics, and verified state-specific coverage are not connected. The network graphic is illustrative.

The redesigned raster logo is in public/inventcare-mark.png. Generated with the built-in image generation tool from the original emblem. Prompt: Redesign InventCare as a minimal geometric medical-legal identity; balanced scales and connecting IC-inspired forms with medical-cross negative space; pale mint on transparency; no lettering, seal, shadows, or mockup.
